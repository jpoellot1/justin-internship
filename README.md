<h1 align="center">Ultraverse NFT Marketplace</h1>


Ultraverse is an NFT Marketplace. 


<h2 align="center">Stack Used</h2>
*React <br/>
*Javascript <br/>
*CSS<br/>
*HTML<br/>
*Axios<br/>
*OwlCarousel

<h2 align="center">Main Features</h2>
*Carousel for the collections on the home page<br/>
*Dedicated pages for each NFT and each author/creator<br/>
*Animate on Scroll to make the page flow smoothly

<h2 align="center">My Conributions</h2>
This was the culmination of my Virtual Internship with Frontend Simplified. We were given the starter code with the basic UI for each page and the API to use to make the website dynamic. <br/>
Here is what I contributed to the project:<br/>
*Used Axios to fetch the NFT data from the RESTful API in order to make the content dynamic<br/>
*Added Skeleton Loading States<br/>
*Created 15 reusable components to reduce code duplication<br/>
*Implemented Animate on Scroll to make the components appear smoothly when scrolling the page<br/>
*Used OwlCarousel to add a carousel to the collections on the home page
